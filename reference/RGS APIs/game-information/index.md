<br />

These APIs allow clients to discover which games are active, access essential game attributes, and configure game launches correctly. The information returned includes game identifiers, display details, technical URLs, RTP values, betting configuration, and win limits.

This data is typically used to:

1. Display the available games in a lobby or game catalog
2. Validate game availability and status
3. Configure game launches and betting parameters
4. Synchronize game metadata with client systems
