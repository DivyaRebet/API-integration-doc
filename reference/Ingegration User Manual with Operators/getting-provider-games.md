## Game Settings Retrieval

Provides all **game-level configuration** required by the frontend or game client to correctly initialize and run a game.

This configuration may vary based on **tenant**, **game version**, or **regulatory rules**.

***

### Configuration Includes

* **RTP & Volatility**
  * Return to Player (RTP) values
  * Volatility / variance settings

* **Reel & Paytable Configuration**
  * Reel strips
  * Paytables and win rules

* **Bet Configuration**
  * Minimum and maximum bet limits
  * Supported bet steps

* **Feature Buy Settings**
  * Availability of feature buy
  * Pricing and constraints

* **Free Spins Configuration**
  * Free spins rules
  * Win limits and restrictions

* **Multi-Currency Support**
  * Supported currencies
  * Currency-specific bet limits and RTP overrides

* **Overrides**
  * Tenant-specific overrides
  * Game version–specific overrides
